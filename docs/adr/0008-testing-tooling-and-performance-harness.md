# ADR-0008: Build, Release, Testing, and Performance Harness

Status: Accepted

## Context

Helio ships as a Swift package (`HelioKit`) wrapped by a thin Xcode app shell (`App/Helio.xcodeproj`) for iOS 26+ and Mac Catalyst 26+, distributed via GitHub Releases with an AltStore/SideStore source feed and a Sparkle Mac appcast. Because CI runners vary across Xcode releases, Mac Catalyst cannot link AppKit or use the keychain without provisioning, and XCUITest's accessibility snapshots add ~20% main-thread overhead, Helio relies on explicit build boundaries, deterministic unit-test concurrency contracts, and an in-process DYLD-injected performance harness (`Tools/perf`).

## Decisions

### 1. Package Layout, Resources, and Mac Catalyst Plugin Boundary

- **App-bundle resource ownership** (`Package.swift`): `HelioKit` contains all application code except the `@main` entry point, while all resources (asset catalog, localization strings, Core Data model, shaders, Lottie animations, media) live in the Xcode app bundle and are resolved via `Bundle.main`.
- **Sparkle AppKit plugin isolation** (`Package.swift`): `Package.swift` declares `.macOS("26.0")` exclusively for `HelioMacUpdater` because Sparkle depends on AppKit and cannot build for Mac Catalyst. `App/HelioMacUpdater` builds that target into a macOS plugin bundle embedded only in the Mac app and loaded at runtime by `MacUpdater`.

### 2. Release Packaging and Update Feeds

- **Sparkle appcast (`gh-pages`)** (`.github/scripts/update-appcast.sh`): Writes `appcast.xml` from `release.yml`'s `mac-update.json` (version, build number, minimum macOS, EdDSA signature, zip length) with only the newest release item, since Sparkle only needs the latest. Release notes are Markdown rather than HTML because Mac Catalyst apps cannot render HTML release notes in Sparkle's update window, and `]]>` sequences are escaped so they cannot terminate CDATA early.
- **AltStore/SideStore source feed** (`.github/scripts/update-source.sh`, `.github/scripts/app-metadata.sh`): Keeps versions ordered newest-first and replaces any matching version entry on re-run so re-tagged releases never duplicate. `appPermissions` is refreshed from build metadata on every release because AltStore validates the IPA's entitlements against what the feed declares. Unsigned builds have no entitlements, so `codesign` produces empty output and `app-metadata.sh` defaults to an empty JSON array.

### 3. CI Simulator Selection and XCUITest Quirks

- **Dynamic simulator selection** (`.github/scripts/simulator-destination.sh`, `Tools/perf/Sources/perf/Simulator.swift`):
  - Simulator names are never hard-coded because they change with each Xcode release and some CI runner images ship without an iOS runtime (in which case the script/tool downloads the iOS platform via `xcodebuild` and creates a device on demand).
  - Runtimes at or above iOS 26 are ranked with general iOS runtimes ahead of device-specific runtimes (such as `iOS-27-1-iPhone19-4`, which only runs iPhone Duo), then newest first. iPhone Duo is skipped because its simulator is slow to start for unit tests and performance benchmarks must measure a consistent regular iPhone layout.
  - In `simulator-destination.sh`, a failed `simctl create` inside a command substitution must return `0` under `set -e` so the caller falls through to the next runtime.
  - Performance runs target `$HELIO_PERF_SIMULATOR` or create a dedicated `"Helio Perf"` simulator so benchmarks do not disturb developer simulators.
- **XCUITest platform quirks** (`App/HelioUITests/SmokeUITests.swift`, `App/HelioUITests/PerfSetupUITests.swift`):
  - On iOS 26, XCUITest's element tap on tab bar items lands left of the icon (on the app's tab overlay slot for the previous tab), and iPad's top tab bar is not exposed as a tab bar. `SmokeUITests` taps the icon center using normalized coordinates relative to the tab element so taps also land accurately when the interface is rotated (e.g., unfolded iPhone Duo).
  - `PerfSetupUITests` drives a fresh install on fixture data through onboarding and What's New so the subsequent benchmark launches as a returning user; it skips unless the perf tool's network shim environment variables are set.

### 4. Unit Testing Infrastructure and Concurrency Contracts

- **SwiftPM test host setup** (`Tests/HelioKitTests/AccountListSyncAuthorizationTests.swift`, `Tests/HelioKitTests/MediaExtractorTests.swift`, `Tests/HelioKitTests/CommentTreeTests.swift`, `Tests/HelioKitTests/MediaScrubTests.swift`):
  - Package tests cannot load the app bundle's Core Data model, so `AccountListSyncAuthorizationTests` constructs an in-memory `NSManagedObjectModel` programmatically matching the app's two account-list entities, attributes, and relationship.
  - Test hosts have no window to report screen scale to renderers or Nuke, so `MediaExtractorTests` seeds `WindowMetrics.displayScale` explicitly.
  - `CommentTreeTests` aliases `HelioKit.Comment` to avoid collision with Swift Testing's `Comment` type.
  - `MediaScrubTests` gives each synthetic GIF frame a distinct shade because ImageIO's GIF encoder merges identical consecutive frames.
- **Serialization, shared state, and deadlock guards** (`Tests/HelioKitTests/QuickActionTests.swift`, `Tests/HelioKitTests/CredentialStoreMutationTests.swift`, `Tests/HelioKitTests/AccountListSyncAuthorizationTests.swift`, `Tests/HelioKitTests/CredentialAuthorizationLeaseTests.swift`):
  - `QuickActionTests` uses `@Suite(.serialized)` and `@MainActor` because tests mutate the global `Nav` singleton whose tab switches finish on the main actor.
  - `CredentialStoreMutationTests` uses synchronous, non-async helpers so shared `Defaults` mutations are always restored before any suspension point where another test could observe them.
  - `AccountListSyncAuthorizationTests.CommitGate` pauses only the private Core Data context queue (never the UI actor). Its 60-second deadline is strictly a deadlock guard—not a performance assertion—sized to tolerate parallel CI suites initializing keychain or Core Data on the UI actor.
  - `CredentialAuthorizationLeaseTests.Gate` coordinates lease contention via explicit condition events with a 0.25s guard window (during which a broken check-then-commit implementation would complete invalidation while a real lease blocks it), runs deliberate lock contention on a raw `Thread` instead of a Swift cooperative executor worker (preventing pool starvation and deadlocks on small CI pools), and forbids any suspension between `gate.attemptMutation()` and the synchronous UI-owned invalidation.
- **Cross-cutting invariants verified by unit tests**:
  - *Mac Catalyst text scaling* (`Tests/HelioKitTests/AccessibilityTests.swift`, `Tests/HelioKitTests/AppearanceTests.swift`): Mac Catalyst has no Dynamic Type (`ContentTextScale.adjusted` always starts from `.large`), and `UIFontMetrics` does not scale there, so `ContentTextScale.macScale` derives explicit scale factors from iOS body sizes.
  - *Theming and contrast* (`Tests/HelioKitTests/AppearanceTests.swift`, `Tests/HelioKitTests/BoxedTests.swift`, `Tests/HelioKitTests/HelioThemeTests.swift`): Theme presets never change `general` (which triggers a restart); comments draw OP names in `badge.subColor` and use `indentColors` over `indentColor` while non-empty; High Contrast overrides link, new-comments, voted/unvoted score, title flair, and NSFW pill colors to achieve 7:1 contrast; `@Boxed` and `HelioTheme` CoW boxing preserve plain `Codable` and `Equatable` value semantics while keeping views small.
  - *Auth, networking, and decoding* (`Tests/HelioKitTests/AuthRedirectTests.swift`, `Tests/HelioKitTests/WebSessionTests.swift`, `Tests/HelioKitTests/FeedRequestTests.swift`, `Tests/HelioKitTests/InfoAuthorizationTests.swift`, `Tests/HelioKitTests/RequestBatchingTests.swift`, `Tests/HelioKitTests/ListingDecodingTests.swift`, `Tests/HelioKitTests/CommandTargetsTests.swift`): Reddit rejects non-`https` OAuth redirects for keys with a secret; unreadable JWTs classify as `.unknown` so they never sign the user out, and Reddit-signed-out web sessions keep the credential `.valid` (with `nil` `renewalKey`) so the user can sign back in; feed requests capture and dispatch with their originating credential across actor boundaries even if the active account changes mid-flight; late responses from a removed grant are never cached or served if the grant is restored; batched Reddit requests are isolated per account (votes, saves, and private subreddit visibility differ); Reddit's comments endpoint `[post listing, comment listing]` depends on wrong-typed listing decode failure so `Either` falls back to comments; Saved pagination can return comment-only pages with zero posts, requiring another page load.
  - *Layout, media, and routing* (`Tests/HelioKitTests/CanvasTests.swift`, `Tests/HelioKitTests/MediaExtractorTests.swift`, `Tests/HelioKitTests/RelayoutTests.swift`, `Tests/HelioKitTests/RouterTests.swift`, `Tests/HelioKitTests/QuickActionTests.swift`): Saved excludes canvas; canvas thumbnails require the shorter side ≥ `pixelWidth` for square center-crops; unknown-dimension images use square `aspectFill` resizing so wide images fill the square placeholder; each post page owns a distinct `YouTubePlayer` so pages and rows never share a `WKWebView`; `Subreddit` hydrates in place preserving reference identity (keeping per-subreddit settings attached) and `subredditFeedName` (the SwiftUI view identity key); open iPhone Duo uses two custom panes because each half is narrower than `NavigationSplitView`'s tiling threshold; and legacy favorite quick actions that stored a placeholder name in `userInfo` fall back to `localizedTitle`.

### 5. Performance Benchmark Harness (`Tools/perf`)

- **In-process DYLD shim architecture** (`Tools/perf/Shim/HelioPerfShim.swift`, `Tools/perf/Sources/perf/Bench.swift`):
  - Built as a dynamic library with `-Xlinker -init -Xlinker _helio_perf_init` and injected via `DYLD_INSERT_LIBRARIES` (never linked into the app) so `start()` runs on load.
  - Drives navigation and scrolling in-process via `$PERF_CMD` (`<seq> mark`, `open`, `scroll`, and Mac `window`/`resize`) instead of XCUITest, avoiding the ~20% main-thread overhead of XCUITest accessibility snapshots.
  - Intercepts every HTTP(S) request by both registering a `URLProtocol` and swizzling `URLSession` factory creation (since Alamofire and Nuke create custom sessions that ignore globally registered protocols), serving local fixtures after configurable `$PERF_LATENCY_MS` / `$PERF_OTHER_LATENCY_MS` delays so nothing reaches the network.
  - Separates Reddit web pages (link previews) from Reddit API requests (`oauth.reddit.com`, `/api/`, `.json`).
  - Generates fixture JPEGs (`p<n>` post images, `t<n>` thumbnails, avatar squares) matching declared fixture preview dimensions and draws random shapes so JPEG compression does not produce unrealistically tiny payloads.
  - Seeds a placeholder keychain credential (`$PERF_SEED_CREDENTIAL`) without an access token so the first request exercises the cold-launch token-refresh path, and suppresses What's New by setting `WhatsNewKit.<version>` in `UserDefaults` (`$PERF_SKIP_WHATS_NEW`).
  - Emits structured telemetry to `$PERF_LOG`: `R` (requests), `M` (250ms CPU, main-thread, footprint, peak, hitch, and frame samples), `P` (markers), and `S`/`W` clock lines.
- **In-memory keychain interposition for unprovisioned Mac builds** (`Tools/perf/Shim/HelioPerfShim.swift`, `Tools/perf/Sources/perf/Bench.swift`):
  - Unprovisioned ad-hoc signed Mac Catalyst perf builds cannot access the real keychain. When `$PERF_MEMORY_KEYCHAIN` is set, `MemoryKeychain` interposes a minimal `SecItem` subset (generic and internet passwords; matching by class, service, account, and server; `kSecMatchLimit` one or all; returning data, attributes, or both) via dyld's interpose table so `KeychainAccess` works without touching the user's keychain.
  - Because dyld interposition only intercepts calls from other images and never intra-library calls, `seedCredential` calls `MemoryKeychain` directly, and disabled `SecItem` wrappers forward directly to the real `SecItem*` symbols without recursing.
- **Mac benchmark isolation, live resize, and hitch calculation** (`Tools/perf/Shim/HelioPerfShim.swift`, `Tools/perf/Sources/perf/Bench.swift`):
  - Mac perf builds compile with an isolated bundle ID and no URL schemes so preferences/state never mix with an installed Helio and `helioapp://` links do not open the benchmark build; `swiftc` passes explicit `System/iOSSupport` paths for Mac Catalyst's UIKit.
  - Each Mac run starts from an empty `CFFIXED_USER_HOME`, launches once to sign in and load the account, deletes `Library/Saved Application State` (so session restoration does not come back windowless), and launches again as a returning user for the measured scenario. `setWindow` places the window at a fixed screen position and brings the app to the front (shell-launched Mac apps start behind other windows, and occluded windows can stop drawing), using `$0.keyWindow ?? $0.windows.first` because a non-frontmost Mac app has no key window.
  - `Resizer` simulates a live drag resize by setting the AppKit window frame once per display frame (preserving `frame.minY` since AppKit's origin is bottom-left) rather than calling `requestGeometryUpdate`, which would animate each step.
  - Hitch detection measures frame interval from `targetTimestamp - timestamp` (a hitch is >1.5× interval) rather than `CADisplayLink.duration`: on 120 Hz Mac displays, `duration` is half the 60 fps requested interval and would misclassify every frame as a hitch.
- **Harness hygiene, deterministic fixtures, and strict budgets** (`Tools/perf/Sources/perf/Bench.swift`, `Tools/perf/Sources/perf/Fixtures.swift`, `Tools/perf/Sources/perf/Metrics.swift`, `Tools/perf/Sources/perf/Profile.swift`, `Tools/perf/Sources/perf/Shell.swift`):
  - `Bench.swift` uses `check: false` on `shell()` where `defer` restores `SmokeUITests.swift` (since `check: true` exits immediately without running `defer`), tracks the last build target via a `platform-mac` marker file (because a subsequent simulator build leaves an older Catalyst bundle on disk), and purges stale `run*` artifacts before each batch so earlier runs cannot skew medians.
  - `Fixtures.swift` generates deterministic synthetic Reddit data (four 25-post Home pages covering all post types, ~160-comment threads, about pages, subscriptions, inbox, and multis) using a custom `SplitMix64` PRNG for cross-machine parity, bumps `Fixtures.version` to invalidate cached fixture directories on data changes, hardcodes scores `[1300, 2400, 3500]` on the first three posts as UI automation anchors, and hardcodes the first root comment body as a load-completion sentinel.
  - `Metrics.swift` distinguishes Reddit API requests from web link previews, discards incomplete or failed-deep-link runs (`nil`) so partial runs cannot artificially lower request counts or timings, assigns budget `0` to any unlisted request kind so unexpected endpoints fail CI, and verifies that Home and post comments actually loaded so a broken 0-request run cannot falsely pass.
  - `Profile.swift` parses `xctrace` deduplicated XML tables (resolving `ref` attributes to earlier element `id`s) and defines busy main-thread runs using a `>2.5ms` sample gap threshold matching Time Profiler's ~1ms sampling cadence.
  - `Paths.repo` in `Shell.swift` derives the repository root by popping 5 path components from `#filePath`, coupling it to its location at `Tools/perf/Sources/perf/Shell.swift`.

## Consequences

- **Positive**: CI unit tests and performance budgets run reliably across changing Xcode images without touching external networks or user keychains; Mac Catalyst performance (including live window resize) is measurable without provisioning; and regressions in Reddit API request counts, concurrency safety, or contrast are caught automatically.
- **Trade-offs**: The perf shim relies on `URLSession` swizzling, `WhatsNewKit.<version>` UserDefaults internals, and dyld `SecItem` interposition, which must be updated if upstream libraries or OS runtimes change; `Fixtures.version` must be bumped manually whenever fixture data changes; and SwiftPM tests that touch Core Data must keep their programmatic `NSManagedObjectModel` in sync with the app bundle's schema.
